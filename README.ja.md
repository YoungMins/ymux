Windows と macOS 向けの軽量な tmux スタイルのターミナルマルチプレクサ。

https://github.com/user-attachments/assets/705fff59-0bda-4460-a87f-d7ba6f50993a

ymux は 1 つのウィンドウを必要な数のターミナルに分割し、レイアウトをワークスペース
ごとに保存して、シェル、スクロールバック、AI コーディングエージェントを整理して
くれます。Tauri 2 (Rust) と xterm.js で構築され、Windows では WebView2、macOS では
WKWebView 上で動作します。

## インストール

### Windows

**Microsoft Store** (ストアでの公開後に利用できます):
<https://apps.microsoft.com/detail/9N20Z9NKD2Q1>。Store 版はシステムの Evergreen
WebView2 ランタイム (Windows 11 に組み込み済み、Windows 10 では Windows Update で
配布) を使用し、`ymux` アプリ実行エイリアスを登録するので、どのターミナルからでも
`ymux` を実行できます。

**MSI**: [Releases](https://github.com/YoungMins/ymux/releases) から
`ymux_*_x64_en-US.msi` をダウンロードして実行してください。インストーラは
WebView2 ブートストラッパを同梱し、インストール先を `PATH` に追加するので、
どのターミナルからでも `ymux` を起動できます。

### macOS (Apple Silicon、macOS 11+)

[Releases](https://github.com/YoungMins/ymux/releases) から
`ymux_*_macos_aarch64.dmg` をダウンロードして開き、ymux を Applications へ
ドラッグしてください。

アプリは ad-hoc 署名のみで、**公証 (notarization) はされていません**。そのため
初回起動時に Gatekeeper が「破損している」または「開発元を確認できない」として
起動を拒否します。ダウンロード隔離属性を一度だけ解除してください:

```sh
xattr -dr com.apple.quarantine /Applications/ymux.app
```

## 機能

### ターミナルとレイアウト

- **永続化されるレイアウト**: 再帰的な水平 / 垂直分割。各ペインは自分のシェル、
  `cwd`、任意の起動コマンドを記憶します。
- **ペインタブ**: `Ctrl+Shift+T` でフォーカス中のペインにタブを追加します。
  非表示のタブも動き続けます。
- **カレントディレクトリの継承**: ペインを分割すると、新しいペインは起動時の
  ディレクトリではなく、親シェルが現在いるディレクトリで開きます (OSC 7 追跡)。
- **シェル自動検出**: Windows では `cmd.exe`、Windows PowerShell、
  PowerShell 7 (`pwsh`)、Git Bash、WSL ディストリビューションを検出します。
  macOS ではログインシェルに加え、見つかった zsh / bash / fish (Homebrew 版を
  含む) を提示します。zsh と bash は自動生成される shim 経由で起動され、shim は
  ユーザー自身の dotfile を先に読み込んでから OSC 7 フックを追加します。
- **永続スクロールバック**: 各ペインのバッファが (色も含めて) 次回起動時に薄い
  *「セッション復元」* 区切り線の下に復元されます。**設定 → 一般** で切り替え
  可能。
- **ペインのズーム、名前変更、検索**: `Ctrl+Shift+Z` で他のペインをすべて隠し、
  `Ctrl+Shift+R` でフォーカス中のペイン名を変更し、`Ctrl+F` でターミナルに検索
  バーを開きます (Enter / Shift+Enter で一致箇所を移動)。
- **プロンプトの下端固定**: 出力がペインより短いとき、プロンプトは下端に固定され、
  出力は上に向かって伸びます。デフォルトでオンで、**設定 → 一般** でオフにできます。
- **クリック可能なリンクとパス**: `Ctrl+クリック` で `http://` / `https://` リンクは
  デフォルトブラウザで、コマンドが出力したファイルパスは OS の既定のプログラムで
  開きます。実行ファイルやスクリプトは実行されず、ファイルマネージャーで表示される
  だけです。
- **テキストと画像の貼り付け**: `Ctrl+V` でテキストを貼り付けます。クリップボードに
  画像がある場合 (例: `Win+Shift+S` のスクリーンショット)、自動クリーンアップ
  される一時ファイルに保存し、引用符で囲んだパスを代わりに入力します。24 時間後に
  削除されます (`paste_image_retention_hours`)。
- **ファイルのドラッグ＆ドロップ**: ファイルやフォルダーをターミナルにドロップすると、
  引用符で囲んだパスがカーソル位置に入力されます。Enter を押すまで何も実行されません。
- **ペインごとの設定 (⚙)**: 任意の背景色と HotKey ボタン (ターミナル上のラベル付き
  ボタンに単一行または複数行のコマンドを割り当て) を設定できます。
- **トレイに閉じる**: ウィンドウを閉じると ymux はトレイ (Windows の通知領域 /
  macOS のメニューバー) に隠れ、すべてのシェルとエージェントは動き続けます。
  トレイアイコンをクリックするか ymux をもう一度起動すると再表示されます (ymux は
  同時に 1 つだけ動きます)。終了はトレイメニュー、macOS の `Cmd+Q`、またはコマンド
  パレットの **ymux を終了** で行い、未保存のエディターがあれば先に確認します。

### ワークスペース

- **番号付きワークスペース**: `Ctrl+Alt+1` .. `Ctrl+Alt+9` で最初の 9 つを切り替え
  ます。ワークスペースパネルの `+` ボタンで追加し、行の `×` で削除します (最後の
  1 つは削除不可)。ワークスペースごとに独自のレイアウトを保存し、切り替えてもペイン
  は生き続けるため、REPL や tail が死ぬことはありません。
- **ワークスペースパネル**: 左側の折りたたみ可能でスクロールできる一覧です。名前を
  ダブルクリックで変更し、行をドラッグして並べ替えます。アクティブなワークスペース
  には枠線が付きます。
- **ワークスペースごとのノート**: 各ワークスペース番号の隣にあるノートボタン、および
  アクティブなワークスペース用の `Ctrl+Alt+N`。`localStorage` に保存されます。
- **Git worktree ペイン**: コマンドパレットの **「新しい git worktree でペインを
  開く」** がブランチ名を尋ね、worktree を作成して (デフォルトの場所: 隣の
  `.ymux-worktrees/<branch>` ディレクトリ、`worktree_base_dir` で変更可能)、その中で
  ターミナルを開きます。ペインを閉じるとき、またはワークスペースを削除するときに
  worktree の削除を確認します。ブランチやコミットには一切触れません。

### AI エージェント

- **エージェント状態を一目で**: 各ターミナルペインが出力の活動とベル / OSC 9 完了
  シグナルから待機 / 実行中 / 完了 / 要注意の状態を示し、色付きのペイン枠線と
  ワークスペース行の色調で表示します。見ていない場所で CLI が終わると OS 通知と
  短いビープ音で知らせます (設定でオフにできます)。
- **ランチャー**: 上部の **+** メニューに、インストール済みのエージェント CLI、
  シェル、GUI ペインが並びます。**エージェントを再検出** を選ぶと一覧を更新します。
- **エージェントツリー**: ワークスペースパネルに、すべてのペインとタブが、そこで動いて
  いるエージェントと共に一覧表示されます。フックで検出する Claude Code セッションと
  サブエージェント、および軽量なプロセススキャンで検出する Codex、Gemini、aider
  などの他の CLI です。行をクリックすると該当ペインにジャンプします。
- **セッションの再開**: Claude Code や Codex が動いているペインで ymux を再起動する
  と、同じ会話を再開します: `claude --resume <id>
  --dangerously-skip-permissions` (すでに承認した内容を再度承認しなくて済むよう常に
  付与されます) または `codex resume <id>`。セッションが最後に活動してから 24 時間
  以内の場合に対象となります。エージェント追跡をオンにしていなくても動作し、CLI
  自身がディスクに残す記録を読み取って見つけます。シェルのみのペインは引き続き
  スクロールバックを復元します。
- **Claude Code フック追跡** (デフォルトはオフ、**設定 → 一般**):
  `~/.claude/settings.json` にユーザーレベルの HTTP フックを追加します。オンの間は、
  ymux の外のセッションも含め、このマシンの *すべての* Claude Code セッションが
  フックイベント (プロンプト、ツールの入力と出力) を `127.0.0.1` の ymux のポートへ
  送ります。ymux は自分のペイン以外から来たイベントを無視し、追跡をオフにするとフック
  は削除されます。追跡がオンのまま ymux が起動していないと、Claude Code はそれらの
  フックの失敗を報告する (例: "Stop hook error occurred") ため、ymux を
  アンインストールする前に追跡をオフにしてください。ymux は補助バイナリを同梱
  しません。

### サイドパネル: ファイルと使用量

すべてのワークスペースで共有される、右側のパネルが 1 つあります。上部のアイコンで
2 つの画面を切り替え、非表示の間もそれぞれの状態を保持します。開閉状態、画面、幅は
保存され、左端をドラッグして幅を変更できます。

- **ファイル**: `Ctrl+Shift+E` で切り替えます。`cd` に合わせてアクティブなペインの
  作業ディレクトリに追従します。ファイル上で Enter を押すと再利用されるエディター
  タブで開き、一覧の下に選択中のファイルやフォルダーのプレビューが表示されます
  (`Tab` で表示 / 非表示)。
- **使用量**: ツールバーの使用量アイコン、**+** ランチャー (*AIトークン使用量*)、
  またはコマンドパレットから開きます。次の内容を表示します:
  - Claude Code と Codex のローカルトークン数。セッションログから読み取り、過去
    5 時間、過去 7 日、または全記録の期間を、AI プロバイダー、モデル、プロジェクト
    別にまとめます。
  - 5 時間 / 週間の残り利用枠とリセットまでのカウントダウン。残りまたは使用済みの
    好きな方で表示できます。利用枠は、それらの CLI がすでに PC に保存しているサインイン
    トークンを使い、Anthropic と OpenAI から直接取得します ([プライバシー](#プライバシー)
    を参照)。

  表示中は 10 秒ごとに更新されます。ローカル合計にはウェブチャットや他の端末は含まれず、
  以前使っていたアカウントが含まれる場合があるため、契約の利用枠とは一致しません。
  利用枠を取得できないときは、記録済みのスナップショットが古い情報として表示されます。

### 内蔵ペイン

ターミナルと並んで ymux 自身が描画する画面です。ターミナルの右クリックメニュー (その
ペインを分割し、作業ディレクトリを引き継ぐ)、**+** ランチャー、またはコマンド
パレットから開きます。

| ペイン | 機能 |
|--------|------|
| **ファイル** | 閲覧、プレビュー、名前変更、新規作成、複数選択、コピー/移動、上書き確認、ごみ箱へ削除 (確認あり) |
| **エディター** | シンタックスハイライト付きテキストエディター: 保存、検索/置換、行へ移動、CRLF/BOM 保持、未保存の変更の確認、クラッシュ対策の下書き保存、外部変更の検出 |
| **Git** | コミットグラフ、ブランチ一覧とチェックアウト、worktree の追加/削除 (確認あり) |
| **ブラウザ** | URL バーと 戻る / 進む / リロード を備えた iframe ブラウザ。URL は切り替えや再起動を越えて保持されます |

> **注意:** ブラウザペインは HTML `<iframe>` なので、`X-Frame-Options` や CSP
> `frame-ancestors` で埋め込みを拒否するサイト (例: github.com、google.com) は
> 読み込めません。ローカル開発サーバー、Storybook、社内ダッシュボード、ドキュメント
> 向けで、一般的な Web ブラウジング用ではありません。

### 生産性

- **コマンドパレット**: `Ctrl+Shift+P`。名前やキーバインドで内蔵の操作をファジー
  マッチで検索できます。
- **システムモニター**: 下部のステータスバーに CPU / RAM / GPU / ディスク /
  ネットワークを 2 秒ごとに表示します。70% で橙、90% で赤に変わります。
- **アップデート通知**: 6 時間ごとにバックグラウンドで GitHub リリースを確認し、
  閉じられるバナーで通知します。自動インストールはしません。
- **Ko-fi で支援**: `⚙` の隣にある ☕ Support ボタンから
  [ko-fi.com/youngminkim](https://ko-fi.com/youngminkim) を開けます。

### カスタマイズ

- **設定 (⚙)**: 一般、シンタックスカラー、ショートカット、設定ファイルの各セクション
  があります。言語の選択、エディターのシンタックスパレットの編集、ショートカット
  リファレンスの確認、`theme.toml` を直接開く操作ができます。
- **13 言語**: English、한국어、日本語、中文、हिन्दी、Español、Français、
  العربية、Português、Русский、Türkçe、Deutsch、Tiếng Việt。右下のステータスバー
  にあるセレクターから切り替えます。
- **埋め込み Web コンテンツからの保護**: すべてのバックエンドコマンドが呼び出し元の
  オリジンを検証するため、ブラウザペイン内のページが ymux の IPC を呼び出すことは
  できません。ymux は他のページにフレームとして埋め込まれると読み込みを拒否し、内蔵
  ブラウザは決められた少数の安全なショートカットのみを転送します。

## キーボードショートカット

macOS では以下の `Ctrl` はすべて `Cmd` になります。そうすることで `Ctrl` がシェル
本来の用途 (`Ctrl+C`、`Ctrl+D`、`Ctrl+R`) にそのまま残ります。例外は表にある 2 つ
です。ペイン巡回は macOS が `Cmd+Tab` をアプリ切り替えに使うため `Ctrl+Tab` の
ままで、ワークスペース切り替えは `Alt` を外します。

| ショートカット (Windows)    | macOS              | 動作                                 |
|-----------------------------|--------------------|--------------------------------------|
| `Ctrl+Shift+H`              | `Cmd+Shift+H`      | ペインを水平分割                     |
| `Ctrl+Shift+V`              | `Cmd+Shift+V`      | ペインを垂直分割                     |
| `Ctrl+Shift+W`              | `Cmd+Shift+W`      | フォーカス中のペインを閉じる         |
| `Ctrl+Shift+T`              | `Cmd+Shift+T`      | フォーカス中のペインに新しいタブ     |
| `Ctrl+Shift+[` / `]`        | `Cmd+Shift+[` / `]` | ペイン内で前 / 次のタブ             |
| `Ctrl+Shift+Z`              | `Cmd+Shift+Z`      | フォーカス中のペインをズーム / 解除  |
| `Ctrl+Shift+←/→`            | `Cmd+Shift+←/→`    | 前 / 次のペインと入れ替え            |
| `Ctrl+Shift+R`              | `Cmd+Shift+R`      | フォーカス中のペインの名前を変更     |
| `Ctrl+Shift+P`              | `Cmd+Shift+P`      | コマンドパレットを開く               |
| `Ctrl+Alt+N`                | `Cmd+Opt+N`        | アクティブなワークスペースのノートを切替 |
| `Ctrl+Shift+E`              | `Cmd+Shift+E`      | サイドパネルを切替 (ファイル画面)    |
| `Ctrl+V`                    | `Cmd+V`            | クリップボードのテキストを貼り付け (画像 → 一時ファイルのパス) |
| `Ctrl+F`                    | `Cmd+F`            | ターミナルのスクロールバックを検索 (エディターペインでは検索 / 置換) |
| `Ctrl+S`                    | `Cmd+S`            | ファイルを保存 (エディターペイン)    |
| `Ctrl+G`                    | `Cmd+G`            | 行へ移動 (エディターペイン)          |
| `Ctrl++` / `Ctrl+-`         | `Cmd++` / `Cmd+-`  | ターミナルの文字サイズを拡大 / 縮小  |
| `Ctrl+0`                    | `Cmd+0`            | ターミナルの文字サイズをリセット     |
| `Ctrl+Tab`                  | `Ctrl+Tab`         | 次のペインにフォーカス               |
| `Ctrl+Shift+Tab`            | `Ctrl+Shift+Tab`   | 前のペインにフォーカス               |
| `Ctrl+Alt+1` .. `Ctrl+Alt+9` | `Cmd+1` .. `Cmd+9` | ワークスペース切り替え              |
| URL/パス上で `Ctrl+クリック` | `Cmd+クリック`     | リンクまたは出力されたファイルパスを既定のプログラムで開く |
| ワークスペース名をダブルクリック | —              | ワークスペース名を変更               |
| ワークスペース行をドラッグ  | —                  | ワークスペースの並べ替え             |
| ターミナル上で右クリック    | —                  | コンテキストメニュー: コピー/貼り付け、分割、ファイル / エディター / Git ペインを開く |
| `⚙` ボタン (ツールバー)     | —                  | 設定を開く (言語、ショートカット、シンタックスカラー、設定ファイル) |

使用量画面にはショートカットがありません。ツールバーの使用量アイコン、**+** ランチャー、
またはコマンドパレットから開いてください。

## 設定

`config.toml` にはワークスペース、レイアウト、キャッシュされたシェルプロファイルが
保存されます。構造が変わるたびに (デバウンスあり) およびアプリ終了時に書き直されます。

`theme.toml` にはエディターのシンタックスカラーを含むカラーパレットが保存されます。
**設定 → シンタックスカラー** で編集するか、**設定 → 設定ファイル → 開く** で
ファイルを直接開けます。

どちらも ymux の設定ディレクトリに置かれます:

| プラットフォーム | パス |
|------------------|------|
| Windows          | `%APPDATA%\ymux\` |
| macOS            | `~/Library/Application Support/ymux/` |

macOS では同じディレクトリに、自動生成されたシェル統合ファイル (`zsh-init/`、
`bash-init.sh`) も置かれます。シェル検出のたびに書き直されるため、削除しても問題
ありません。

## プライバシー

ymux にはアカウント、アナリティクス、テレメトリがなく、サーバーも運用していません。
レイアウト、スクロールバック、ノート、設定はすべて PC 内に留まります。ymux が自発的に
行うリクエストは GitHub のアップデート確認だけで、使用量画面を使う場合は、それらの
CLI がすでにローカルに保存しているトークンを、そのトークンを発行したプロバイダーに
送る形で、Anthropic と OpenAI に利用枠を問い合わせるリクエストが加わります。詳しくは
[プライバシーポリシー](./packaging/microsoft-store/PRIVACY.md)をご覧ください。

## 開発

必要なもの: Rust (stable)、Node 20+、pnpm。

```sh
pnpm install
pnpm tauri dev          # run in dev mode
pnpm tauri build        # MSI on Windows, .app + .dmg on macOS
pnpm test               # fmt + tsc + clippy + tests
npx tsc --noEmit        # TypeScript type check
cargo clippy --workspace -- -D warnings
cargo test -p ytheme -p ypath
cargo test --no-default-features --lib -p ymux
```

`tauri build` は実行したホストに対応するインストーラを生成します (MSI バンドラは
Windows 専用、DMG バンドラは macOS 専用で、リリースワークフローもそうしています)。
Linux でも Rust クレートは `cargo check --no-default-features --lib --tests -p ymux`
がクリーンに通りますが、デスクトップアプリ自体は Linux 向けには配布していません。

メンテナー向け: Microsoft Store 用の MSIX パッケージは `scripts/package-msix.ps1` で
ビルドします。
[packaging/microsoft-store/README.md](./packaging/microsoft-store/README.md) を
