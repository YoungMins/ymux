Windows と macOS 向けの軽量な tmux スタイルのターミナルマルチプレクサ。

https://github.com/user-attachments/assets/705fff59-0bda-4460-a87f-d7ba6f50993a

Tauri 2 (Rust) + xterm.js で構築され、Windows では WebView2、macOS では
WKWebView 上で動作します。軽量かつ高速にネイティブ動作しながら、保存される
レイアウト、ペインごとの作業ディレクトリと起動コマンド、切り替え可能なシェル
(Windows: cmd / PowerShell / pwsh / Git Bash / WSL、macOS: zsh / bash / fish)、
そして各々が独自のレイアウトを記憶する番号付きワークスペースを提供します。

## インストール

### Windows

[Releases](https://github.com/YoungMins/ymux/releases) から
`ymux_*_x64_en-US.msi` をダウンロードして実行してください。インストーラは
WebView2 ブートストラッパを同梱し、インストール先を `PATH` に登録するので、
どのターミナルからでも `ymux` を起動できます。

### macOS (Apple Silicon、macOS 11+)

[Releases](https://github.com/YoungMins/ymux/releases) から
`ymux_*_macos_aarch64.dmg` をダウンロードして開き、ymux を Applications へ
ドラッグしてください。

アプリは ad-hoc 署名のみで、**公証 (notarization) はされていません**。その
ため初回起動時に Gatekeeper が「破損している」または「開発元を確認できない」
として起動を拒否します。ダウンロード隔離属性を一度だけ解除してください:

```sh
xattr -dr com.apple.quarantine /Applications/ymux.app
```

## 機能

- **永続化されるレイアウト**: 再帰的な水平 / 垂直分割。各ペインは自分のシェル、
  `cwd`、任意の起動コマンドを記憶します。
- **カレントディレクトリの継承**: ペインを分割すると、起動時のディレクトリではなく、
  親シェルが現在いるディレクトリで新しいペインが開きます。
  OSC 7 エスケープシーケンスによるリアルタイム追跡を使用しています。
- **シェル自動検出**: Windows では `cmd.exe`、Windows PowerShell、
  PowerShell 7 (`pwsh`)、Git Bash、WSL ディストリビューションを検出します。
  macOS ではログインシェルに加え、見つかった zsh / bash / fish (Homebrew 版を
  含む) を提示します。zsh と bash は自動生成されるシェル統合 shim 経由で起動
  され、shim はユーザー自身の dotfile を先に読み込んでから OSC 7 フックを
  追加します。そのため設定ファイルを一切触らずにリアルタイムの `cwd` 継承が
  動作します。
- **番号付きワークスペース**: `Ctrl+Alt+1` .. `Ctrl+Alt+9` で最初の 9 つの
  ワークスペースを切り替えます。ワークスペースパネルの `+` ボタンで上限なく
  いつでも追加でき、ワークスペース行にマウスを合わせると表示される `×` で
  削除できます (最後の 1 つは削除不可)。すべてのワークスペースは独自のレイアウト
  を保存します。ペインは切り替えを越えて生存し続けるため (tmux スタイル)、REPL
  や tail が死ぬことはありません。ワークスペース名をダブルクリックすると名前を
  変更でき、アクティブなワークスペースはブロック全体が枠線で強調されます。
- **Git worktree ペイン**: コマンドパレットの **「新しい git worktree でペインを
  開く」** でブランチ名を入力すると、git worktree を作成し (デフォルトの場所:
  リポジトリの隣の `.ymux-worktrees/<ブランチ>` ディレクトリ、
  `worktree_base_dir` で変更可能)、その中に移動済みのターミナルペインを開きます
  — AI エージェントや実験ごとに隔離されたチェックアウトを持てます。ペインを
  閉じるとき、またはワークスペース全体を削除するときに worktree の削除を確認
  します (ブランチやコミットには一切触れません)。
- **永続スクロールバック**: ターミナル出力がアプリ再起動後も維持されます。
  各ペインのバッファが (色も含めて) 次回起動時に薄い *「セッション復元」*
  区切り線の下に復元されます。**設定 → 一般** で切り替え可能。
- **トレイに閉じる**: ウィンドウを閉じると ymux はトレイ（Windows の通知領域 /
  macOS のメニューバー）に隠れ、シェルとエージェントは動き続けます。トレイ
  アイコンをクリックすると再表示されます。終了はトレイメニューの **終了** か
  macOS の `Cmd+Q`、またはコマンドパレットの **ymux を終了** で行い、未保存のエディタがあれば先に確認します。
- **エージェント状態を一目で**: 各ターミナルペインが出力の活動とベル / OSC 9
  完了シグナルからプロセスの状態 — 待機 / 実行中 / 完了 / 要注意 — を追跡し、
  色付きのペイン枠線とワークスペースパネルの行の色調で表示します。見ていない
  ペインの CLI が終わると OS 通知と短いビープ音でも知らせます (設定でオフに
  できます)。
- **エージェントセッションの再開**: Claude Code や Codex が動いているペインで
  ymux を再起動すると、古いスクロールバックを表示する代わりに同じ会話を
  再開します — `claude --resume <id> --dangerously-skip-permissions`
  (すでに承認した内容を再度承認しなくて済むよう常に付与されます) または
  `codex resume <id>`。セッションが最後に活動してから 24 時間以内である
  必要があります。エージェント追跡をオンにしていなくても動作します —
  CLI 自身がディスクに残すセッション記録からセッション id を見つけます。
  シェルのみのペインは影響を受けず、今まで通りスクロールバックを復元します。
- **エージェントツリー**: ワークスペースパネルに各ワークスペースのペイン
  (とタブ) が、そこで動いているコーディングエージェントと共に一覧表示され
  ます — フックで検出する Claude Code セッションとサブエージェント、および
  軽量なプロセススキャンで検出する Codex、Gemini、aider などの他の CLI。
  行をクリックすると該当ペインに直接ジャンプします。Claude Code のフック
  追跡はデフォルトでオフで、**設定 → 一般** で有効にできます。
  オンにすると `~/.claude/settings.json` にユーザーレベルの HTTP フックが追加される
  ため、オンの間は ymux の外のセッションも含め、このマシンの *すべての* Claude Code
  セッションがフックイベント（プロンプト、ツールの入力と出力）を `127.0.0.1` の
  ymux のポートへ送ります。ymux は自分のペイン以外から来たものを無視し、追跡を
  オフにするとフックは削除されます。
- **ペインごとの設定 (⚙)**: 各ターミナルの `⚙` ボタンで**背景色**（カラーピッカー）
  と **HotKey ボタン**（単一行またはバッチコマンド）を管理。背景色は再起動後も
  保持されます。
- **ブラウザペイン**: ツールバーの `+ Browser` ボタンで任意のレイアウトスロットに
  iframe ベースのブラウザを配置できます。戻る / 進む / リロード付きの URL バー。
  URL はワークスペース切替やアプリ再起動を越えて保持されます。
  > **注意:** ブラウザペインは HTML `<iframe>` で実装されているため、
  > `X-Frame-Options` や CSP `frame-ancestors` で埋め込みを拒否するサイト
  > (例: github.com、google.com) は読み込めません。ローカル開発サーバー、
  > Storybook、社内ダッシュボード、API ドキュメント、localhost プレビュー
  > など、**開発用途に適しています**。一般的な Web ブラウジング用ではありません。
- **ファイルドック**: `Ctrl+Shift+E` で右側のファイルパネルの開閉を切り替え
  ます。このパネルは `cd` するたびにアクティブペインの作業ディレクトリに追従
  します。ファイル上で Enter を押すと、ドックに留まらず再利用されるエディター
  タブでそのファイルが開きます。ファイル一覧の下に選択中のファイル・フォルダの
  プレビューがあり、`Tab` で表示を切り替えられます。ドックの左端をドラッグ
  すると幅を変えられます。
- **ペイン拡大**: `Ctrl+Shift+Z` でフォーカス中のペイン以外を隠して集中できます。
  もう一度押すと分割状態に戻ります。
- **スクロールバック検索**: `Ctrl+F` でフォーカス中のターミナルに検索バーを
  開きます。Enter / Shift+Enter で次/前のマッチへ、Esc で閉じます。
- **ペイン名の変更**: `Ctrl+Shift+R` でフォーカス中のペインにカスタムタイトルを
  設定できます。
- **プロンプトの下端固定**: ターミナルの出力がペインより短いとき、プロンプト
  は上寄りではなく下端に固定され、出力は上に向かって伸びます。デフォルトで
  オンで、**設定 → 一般** でオフにできます。
- **アップデート通知**: バックグラウンドポーラが 6 時間ごとに GitHub リリースを
  確認し、新しいバージョンがあれば閉じられるバナーで通知します。
  自動インストールはしません。
- **システムモニターのステータスバー**: ウィンドウ下部の細いバーが、CPU / RAM /
  GPU / ディスク / ネットワーク ↑↓ を 2 秒ごとにリアルタイム表示します。
  70% 以上で橙、90% 以上で赤にハイライトされます。マルチ GPU / マルチディスクも
  対応 (3 台以下はインライン、それ以上はサマリー + ツールチップ)。
- **Ko-fi 支援ボタン**: `⚙` ボタンの隣にある ☕ Support ボタンから
  [ko-fi.com/youngminkim](https://ko-fi.com/youngminkim) をシステムブラウザで
  開けます。
- **クリック可能なリンクとパス**: ターミナル内の `http://` または `https://`
  リンクを `Ctrl+クリック` するとデフォルトブラウザで開きます。コマンド出力に
  表示されたファイルパス (`cat`、`git log`、エージェントの回答など) も
  `Ctrl+クリック` で OS の既定のプログラムで開けます。実行ファイルやスクリプト
  は実行されず、ファイルマネージャーで表示されるだけです。
- **設定パネル (⚙)**: WinUI 3 スタイルのモーダルで、左側にメニュー（一般、
  シンタックスカラー、ショートカット、設定ファイル）、右側にコンテンツ
  が表示されます。表示言語の変更、エディターペインのシンタックスハイライト用
  カラーパレットをカラーピッカーで編集、内蔵のショートカットリファレンス
  の確認、`theme.toml` をデフォルトエディタでワンクリックで開けます。
- **コマンドパレット**: `Ctrl+Shift+P` で VS Code スタイルの検索可能な
  コマンドオーバーレイを開きます。名前やキーバインドでファジーマッチ。
- **ワークスペースごとのノート**: 各ワークスペース番号の隣にノートアイコンが
  あり、そのワークスペース専用のノートを開けます。`Ctrl+Alt+N` で現在
  アクティブなワークスペースのノートをトグル。ノートは `localStorage` に
  自動保存されセッションを越えて維持され、内容のあるワークスペースの
  アイコンはアクセントカラーで強調表示されます。
- **クリップボード貼り付け — テキストと画像**: `Ctrl+V` でクリップボード
  テキストをターミナルに貼り付けます。クリップボードに**画像**がある場合
  (例: `Win+Shift+S` のスクリーンショット)、自動クリーンアップされる一時
  ファイルに保存し、引用符で囲んだパスを代わりに入力します — スクリーン
  ショットをペイン内の Claude Code などの AI CLI にそのまま渡せます。
  貼り付けた画像は 24 時間後に削除されます
  (`paste_image_retention_hours` で調整可能)。
- **ファイルをドラッグしてパスを入力**: ファイルやフォルダーをターミナル
  ペインにドロップすると、引用符で囲んだパスがカーソル位置に入力されます。
  フォーカス中ではなく**ドロップしたペイン**に入ります。Enter は送りません。
- **13言語対応**: English、한국어、日本語、中文、हिन्दी、Español、Français、
  العربية、Português、Русский、Türkçe、Deutsch、Tiếng Việt。ステータスバー
  右下の言語セレクターから変更可能。
- **MSI で PATH 自動登録**: インストールディレクトリがシステム PATH に追加され、
  `ymux` がすぐ実行可能。
- **軽量**: Tauri バイナリ + WebView2。インストーラのターゲットは 10 MB 未満。
- **埋め込み Web コンテンツからの保護**: すべてのバックエンドコマンドが呼び出し元
  のオリジンを検証するため、ブラウザペイン内のページが ymux 自身の IPC を
  呼び出すことはできません。ymux は他のページにフレームとして埋め込まれると
  読み込みを拒否し、内蔵ブラウザはプロセス起動やペインを閉じるような操作を
  含まない、決められた少数の安全なショートカットのみを転送します。

### ツールペイン

ファイル、エディター、Git の画面は、ターミナルやブラウザと並んで ymux 自身が
描画するペインです。ターミナルの右クリックメニュー（そのペインを分割し、作業
ディレクトリを引き継ぐ）またはコマンドパレットから開きます。

| ペイン | 開き方 | 機能 |
|--------|--------|------|
| **ファイル** | 右クリック → *ここでファイルを表示*、ファイルドック | 閲覧、プレビュー、名前変更、新規作成、複数選択、コピー/移動、上書き確認、ごみ箱へ削除（確認あり） |
| **エディター** | 右クリック → *分割: エディターペイン*、ファイル上で Enter | シンタックスハイライト付きテキストエディター — 保存、検索/置換、行へ移動、CRLF/BOM 保持、未保存の変更の確認、クラッシュ対策の下書き保存、外部変更の検出 |
| **Git** | 右クリック → *ここで Git* | コミットグラフ、ブランチ一覧とチェックアウト、worktree の追加/削除（確認あり） |

単体コマンドの `ydir` / `ycode` / `ygit` / `ymon`、`y` ランチャー、`y` フック中継は
なくなり、ymux は補助バイナリを同梱しません。エージェント追跡は Claude Code の
HTTP フックで `127.0.0.1` の ymux にイベントを送ります — アップグレード後の初回起動で
古い `y` フックの項目は自動的に置き換わります。追跡がオンのまま ymux が起動していない
と、Claude Code のセッションにフックの失敗が表示されるため（例: "Stop hook error
occurred"）、ymux をアンインストールする前に **設定 → 一般** で追跡をオフにしてください。

## 開発

必要なもの: Rust (stable)、Node 20+、pnpm (または npm)。

```sh
pnpm install
pnpm tauri dev          # 開発モードで実行
pnpm tauri build        # Windows では MSI、macOS では .app + .dmg
```

`tauri build` は実行したホストに対応するインストーラを生成します。MSI バンドラ
は Windows 専用、DMG バンドラは macOS 専用なので、各インストーラはそれぞれの
プラットフォーム上でビルドする必要があります (リリースワークフローもそうして
います)。

Linux でも Rust クレートは `cargo check` がクリーンに通るため、プラットフォーム
非依存のロジックはそこで開発できます。ただしデスクトップアプリ自体は Linux 向け
には配布していません。

## 設定

`config.toml` にワークスペース、レイアウト、キャッシュされたシェルプロファイル
が保存されます。構造変更のたびに (デバウンスあり) およびアプリ終了時に書き直され
ます。

`theme.toml` にはエディターペインのシンタックスハイライト色を含むカラー
パレットが保存されます。**設定 → シンタックスカラー**
のカラーピッカーで編集するか、**設定 → 設定ファイル → 開く** でファイルを直接
開けます。

どちらも ymux の設定ディレクトリに置かれます:

| プラットフォーム | パス |
|------------------|------|
| Windows          | `%APPDATA%\ymux\` |
| macOS            | `~/Library/Application Support/ymux/` |

macOS では同じディレクトリに、自動生成されたシェル統合ファイル (`zsh-init/`、
`bash-init.sh`) も置かれます。シェル検出のたびに書き直されるため、削除しても
問題ありません。

## キーボードショートカット

macOS では以下の `Ctrl` はすべて `Cmd` になります。そうすることで `Ctrl` が
シェル本来の用途 (`Ctrl+C`、`Ctrl+D`、`Ctrl+R`) にそのまま残ります。例外は表に
ある 2 つです。ペイン巡回は macOS が `Cmd+Tab` をアプリ切り替えに使うため
`Ctrl+Tab` のままで、ワークスペース切り替えは `Alt` を外します。

| ショートカット (Windows)       | macOS              | 動作                                |
|--------------------------------|--------------------|-------------------------------------|
| `Ctrl+Shift+H`                 | `Cmd+Shift+H`      | ペインを水平分割                    |
| `Ctrl+Shift+V`                 | `Cmd+Shift+V`      | ペインを垂直分割                    |
| `Ctrl+Shift+W`                 | `Cmd+Shift+W`      | フォーカス中のペインを閉じる        |
| `Ctrl+Shift+T`                 | `Cmd+Shift+T`      | フォーカス中のペインに新しいタブ    |
| `Ctrl+Shift+[` / `]`           | `Cmd+Shift+[` / `]` | ペイン内で前 / 次のタブ            |
| `Ctrl+Shift+Z`                 | `Cmd+Shift+Z`      | フォーカス中のペインをズーム / 解除 |
| `Ctrl+Shift+←/→`               | `Cmd+Shift+←/→`    | 前 / 次のペインと入れ替え           |
| `Ctrl+Shift+R`                 | `Cmd+Shift+R`      | フォーカス中のペインの名前を変更    |
| `Ctrl+Shift+P`                 | `Cmd+Shift+P`      | コマンドパレットを開く              |
| `Ctrl+Alt+N`                   | `Cmd+Opt+N`        | 現在のワークスペースのノートを切替  |
| `Ctrl+Shift+E`                 | `Cmd+Shift+E`      | ファイルドックを切替                |
| `Ctrl+V`                       | `Cmd+V`            | クリップボードのテキストを貼り付け (画像 → 一時ファイルのパス) |
| `Ctrl+F`                       | `Cmd+F`            | ターミナルのスクロールバックを検索 (エディターペインでは検索 / 置換) |
| `Ctrl+S`                       | `Cmd+S`            | ファイルを保存 (エディターペイン)   |
| `Ctrl+G`                       | `Cmd+G`            | 行へ移動 (エディターペイン)         |
| `Ctrl++` / `Ctrl+-`            | `Cmd++` / `Cmd+-`  | ターミナルの文字サイズを拡大 / 縮小 |
| `Ctrl+0`                       | `Cmd+0`            | ターミナルの文字サイズをリセット    |
| `Ctrl+Tab`                     | `Ctrl+Tab`         | 次のペインにフォーカス              |
| `Ctrl+Shift+Tab`               | `Ctrl+Shift+Tab`   | 前のペインにフォーカス              |
| `Ctrl+Alt+1` .. `Ctrl+Alt+9`   | `Cmd+1` .. `Cmd+9` | ワークスペース切り替え              |
| URL/パス上で `Ctrl+クリック`   | `Cmd+クリック`     | リンクまたは出力されたファイルパスを既定のプログラムで開く |
| ワークスペース名をダブルクリック | —                | ワークスペース名を変更              |

> シンタックスハイライトパレットの編集、`theme.toml` などの設定ファイルを直接開く操作
